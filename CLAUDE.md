# The Way («Догоню») — контекст проекта

Кооперативный 3D-платформер от третьего лица о двух собаках-друзьях, Хьюстоне и Сэме, которые ищут дорогу домой. Локальный кооп на двоих со split-screen (как в It Takes Two) и одиночная игра с переключением между собаками. Атмосфера и повествование без слов — как в Stray.

Автор сюжета и геймдизайна — пользователь (опыт программирования есть, опыта в геймдеве нет). Весь код пишет AI. Объясняй решения простыми словами: пользователь должен понимать архитектуру своего проекта.

## Герои и механики
| | Хьюстон | Сэм |
|---|---|---|
| Характер | смелый, безрассудный, любопытный | осторожный, тревожный, чуткий |
| Способности | толкать/тащить тяжёлое, ломать хлипкое, лай отвлекает, плавать | чутьё (видит запаховые следы и опасности), красться, подкапывать, точные прыжки |
| Общее | бег, прыжок, взять в зубы, лай, позвать напарника | |

Core loop: исследовать → найти препятствие → объединить способности обоих → пройти → сюжетная сцена → новая локация.
Собаки «говорят» лаем; смысл передают субтитры-«перевод». Люди говорят голосом.

## Стек (фактические версии)
- Unity 6000.3.26f1 (Unity 6.3 LTS), рендер — URP 17.3. Ассеты PC_RPAsset / PC_Renderer — основные.
- Input System 1.20 — только новая система ввода. `UnityEngine.Input` не использовать.
  Split-screen — через `PlayerInputManager` (Split Screen включён), у каждого игрока свой `PlayerInput` и своя камера.
- Cinemachine 3.1.7. ВНИМАНИЕ: это Cinemachine 3, API отличается от CM2:
  namespace `Unity.Cinemachine`, компонент `CinemachineCamera` (не `CinemachineVirtualCamera`),
  `CinemachineOrbitalFollow` / `CinemachineRotationComposer` вместо старых Body/Aim.
- Timeline — сюжетные сцены. Ink — субтитры и реплики (пакет ещё не установлен).
- Git + Git LFS (тяжёлые ассеты — в LFS, см. `.gitattributes`).
- Машина разработчика: MacBook Pro 16 M1, 16 ГБ. Целевые платформы: Windows (основная), macOS.
  Следи за производительностью: split-screen рисует сцену дважды.

## Структура
```
Assets/
  _Game/            ← всё наше; импортированные паки лежат рядом в своих папках
    Scripts/        ← C#, namespace TheWay.<Модуль>
      Dogs/         ← контроллер, способности, анимации собак
      Players/      ← ввод, split-screen, переключение собак
      Camera/
      Interaction/  ← толкаемые, ломаемые, подбираемые объекты
      Narrative/    ← субтитры, катсцены
      Core/         ← загрузка сцен, сохранения, события
    Prefabs/
    Scenes/
    Art/            ← модели, материалы, текстуры
    Audio/
    Narrative/      ← файлы Ink
    Settings/       ← ScriptableObject-настройки
```

## Архитектура
- У каждой собаки есть «контроллер»: либо живой игрок (`PlayerInput`), либо переключатель в одиночной игре.
  Логика собаки не знает, кто ей управляет — она получает команды через общий интерфейс.
- Способности — отдельные компоненты (`PushAbility`, `ScentAbility` и т.д.), а не один огромный класс.
- Числовые настройки (скорость, сила прыжка) — в ScriptableObject, не захардкожены.
- Связь между системами — через события/интерфейсы, без цепочек `FindObjectOfType`.

## Правила работы
1. Маленькие задачи: одна задача — одна понятная функция, которую можно проверить в редакторе.
2. После каждого рабочего шага предлагай коммит с понятным сообщением на русском.
3. Перед крупными изменениями кратко опиши план и дождись согласия.
4. Не трогай `Library/`, `Temp/`, `Logs/`, `UserSettings/`. Не редактируй `.meta` вручную.
   Не переименовывай и не перемещай ассеты вне Unity — сломаются ссылки (GUID).
5. Сцены и префабы (`.unity`, `.prefab`) правь в YAML только если иначе никак; лучше скрипты-инструменты в `Editor/`
   или пошаговая инструкция, что сделать в редакторе.
6. Проверить, как игра ощущается, может только пользователь в Play Mode. После изменений говори, что именно проверить.
7. Комментарии в коде — на русском, имена в коде — на английском. Один класс — один файл. Поля — `[SerializeField] private`.
8. Если ошибка не уходит после 2–3 попыток — остановись, опиши проблему и предложи другой подход.

## Ближайшая цель — прототип (Фаза 2)
- Greybox-уровень из примитивов.
- Две собаки-заглушки (капсулы разного размера и цвета): бег, прыжок, камера от третьего лица.
- Split-screen на два геймпада; в одиночном режиме — переключение собак кнопкой.
- Одна совместная головоломка: Хьюстон двигает ящик, Сэм по нему забирается и открывает путь.
- Проверка FPS в split-screen на M1.
